# GEO Probe Schema（AI 引用实测的统一字段）

> 这个 schema 被两处引用：
> - `brief.md §2`：**AI 认知探针**（写作前的基线抽样）
> - `report.md §7.3.1`：**GEO 复测探针**（T+3/14/45/90 的追测）
>
> 两处字段**必须同构**——这样前后对照（基线 vs 复测）才能直接比较。改字段只改本文件。

---

## 表结构（硬）

| 列名 | 语义 | 填法 |
|---|---|---|
| `query` | 测试查询（来自 brief §3 意图语料库的代表子集） | 原文照贴 |
| `ai_platform` | 在哪个 AI/SERP 上实测 | Perplexity / ChatGPT / Claude / Google AIO / 百度 / 知乎 / SGE，任选主流 |
| `brand_cited` | 本品牌/本站是否被引用 | 是 / 否 |
| `cited_url` | 若被引，引用到的具体 URL | 完整 URL；否则留空 |
| `rank` | 被引用时的位序（AI 引用池里第几条 / SERP 排名） | 整数；否则留空 |
| `top_cited_domains` | 该查询下 Top 3 被引域名 | 用 "/" 分隔 |
| `competitor_cited` | 竞品品牌是否被引 | 竞品名；多个用 "/" 分隔；否则留空 |
| `narrative_angle` | 观察到的叙事角度（AI 用什么原型在回答） | 短语，如 "权威数据" / "便宜快" / "踩坑故事" |
| `note` | 备注（截图路径 / 异常 / 特殊观察） | 自由文本 |

---

## 汇总指标（每次探针必算）

- **AI 引用覆盖率** = 被引查询数 / 抽样总数
- **品牌 SOV（Share of Voice）** = 本品牌被引次数 / (本品牌 + 所有竞品被引次数)
- **主要被引竞品** = 出现 ≥ 2 次的竞品列表

---

## 两处使用约定

### brief §2 基线抽样（写作前）

- **抽样量**：≥ 5 条代表性查询（1 信息类、1 实操类、1 对比类、1 本地类、1 长尾）
- **目的**：回答"AI 目前在讲什么、引谁、我有没有声音"——用来决定 brief §4 支柱-集群结构的切入点
- **工具优先级**：见 SKILL.md §Step 2 的工具清单

### report §7.3.1 复测（上线后）

- **抽样量**：T+3 时 ≥ 5 条；T+14/45/90 时 ≥ 8 条或全量
- **目的**：回答"本品牌被引了吗 / 位序 / SOV 变化 / 竞品换人了吗"
- **对照**：和 brief §2 的基线表横向比——哪些查询新获得了引用，哪些丢了
- **原始材料**：截图/摘要落 `output/<task>/.workspace/probe/T+N/`
