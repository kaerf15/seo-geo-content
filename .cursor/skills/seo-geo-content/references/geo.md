# SEO / GEO 方法论

营销主链不变：**信念 → 行动**。SEO / GEO 只放大「可被找到、可被摘引」，不替代钩子与 CTA。

## SEO（搜索引擎）

### 主查询从哪来

按优先级：

1. **用户给定** — 直接使用，不擅自改义
2. **从主题推断** — 用「{受众} + {问题/场景} + {品类/解法}」拼 1 个主查询；长文再拆 3–5 个长尾（每个对应一个 `##`）
3. **从平台反推** — 标题即问题的平台（CSDN、百家号、Landing）以标题为主查询

### 落地规则

| 规则 | 做法 |
|------|------|
| 主查询可见 | 出现在标题或首段前 2 句 |
| 一节一题 | 每个 `##` 对应一个可搜索问题；小节标题含关键词但可读 |
| 内链 | `own_blog`、`landing_page` 正文链到相关页；锚文本用自然短语，不堆关键词 |
| Meta | `landing_page`、`own_blog` 产出末尾加 **发布元数据** 块（见 formats.md），含 description ≤160 字 |

## GEO（生成式引擎 / AI 摘引）

**本质**：每个信息块能**单独被摘引**且**可核对**。

### 原子块规则

| 块类型 | 字数 | 要求 |
|--------|------|------|
| 首段直答 | 40–80 字 | 一句定义或判断 + 一句边界（适合谁/不适合谁） |
| FAQ 单条 | 30–120 字 | 问句完整；答句先结论后一句理由；不依赖上下文 |
| `##` 小节首句 | ≤40 字 | 该节结论；后文展开 |

### 实体一致性

全文统一，禁止同一事物多种叫法：

- 品牌名、产品名、版本号 — 与用户给定或事实依据一致
- 英文专有名 — 首次出现可「中文（English）」，之后固定一种
- 数据 — 无来源不写；有来源写「据 {来源}」

### 可核对主张

每条关键判断必须满足其一：

- 有出处（链接、报告、官方文档）
- 是可验证的操作步骤
- 是明确观点并标「我认为 / 经验上」
- 写不出处则**删掉或弱化**为「可能 / 视场景而定」

### 平台 GEO 策略

| 平台 | GEO 动作 |
|------|----------|
| `baijiahao` `landing_page` | 首段直答 + `## 常见问题` 3–8 条 |
| `own_blog` | 首段直答 + FAQ 可选 + Schema 元数据 |
| `zhihu` | 开头 100 字内给完整短答 |
| 其余长文 | 首段含定义/判断即可 |

## 多平台同一主题

详见 [adaptation.md](./adaptation.md)。GEO 注意：**canonical 内容**写在 `landing_page` 或 `own_blog`；其它平台摘取钩子与论证链，FAQ 不整段复制。
