# GEO 原子块

营销主链不变：**信念 → 行动**。GEO 只让信息块**可单独摘引**且**可核对**。

> **output 规则**：下列块是**写法要求**，不是要在正文里打标签。首段直答写成自然段，勿写「**短答**：」；小节结论写进首句，勿写「**结论**：」。

## 原子块

| 块 | 字数 | 要求 |
|----|------|------|
| 首段直答 | 40–80 | 一句定义或判断 + 一句边界（适合谁/不适合谁）；自然段呈现 |
| FAQ 单条 | 30–120 | 问句完整；答句先结论后理由；不依赖上下文 |
| `##` 小节首句 | ≤40 | 该节结论；后文展开 |

## 实体与主张

- 品牌名、产品名、版本号 — 与用户给定或事实依据一致
- 英文专有名 — 首次「中文（English）」，之后固定一种
- 关键判断须满足其一：有出处 / 可验证步骤 / 明确标「我认为」— 否则弱化或删除

## 主查询

1. 用户给定 → 直接用  
2. 从主题推断 → `{受众} + {问题} + {品类}`  
3. 标题即问题的平台（CSDN、百家号、Landing）→ 以标题为主查询

主查询出现在标题或首段前 2 句；每个 `##` 对应一个可搜索问题。

多平台同一主题 → [adaptation.md](./adaptation.md)
