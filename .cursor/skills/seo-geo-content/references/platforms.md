## 形态默认

**长文（中文）**：钩子或结论前置 → `##` 分节 → 收尾 CTA。  
**长文（英文）**：Hook → sections → clear CTA。  
**开发者**：结论 → 环境/步骤 → 代码 → 坑点 → 参考（[_dev_article.md](./platforms/_dev_article.md)）。  
**短视频**：口播可照读 + 分镜表（见 formats.md 模板）。  
**站内**：首段直答「是什么/适合谁/为何现在」+ 发布元数据。
