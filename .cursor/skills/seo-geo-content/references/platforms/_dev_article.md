# 开发者长文（juejin / csdn / cnblogs / devto）

共享正文骨架。平台差异（标签、字数、分类）见各平台卡 **约束** 与 **分发要点**。

产出格式 → [formats.md](../formats.md)

```markdown
# {标题}

> {帮谁解决什么 — 一句话}

## 先给结论

- **场景**：…
- **推荐**：…
- **不适用**：…

## 环境 / 前置

- OS / 版本 / 依赖

## {做法}

{说明 + 代码块}

## 坑点与边界

1. …

## 参考来源

- [来源](url)
```

## 写作要点

- **结论节**：读者 30 秒内能决定要不要继续
- **代码**：可复制；注释说明非显而易见处
- **坑点**：写真实失败场景，不写「暂无」
- **SEO**：标题 = 问题；H2 = 子问题
