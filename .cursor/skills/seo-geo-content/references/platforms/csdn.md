# CSDN 博客

> 标题即搜索问题；环境、步骤、示例写清。

产出格式 → [formats.md](../formats.md) + [_dev_article.md](./_dev_article.md)

## 约束

- **篇幅**：1000–2500 字
- **标题**：≤70 字
- **语气**：technical, practical, direct
- **忌**：品牌宣传腔；无步骤或示例
- **结构**：结论前置 → 环境 → 分步解法 → 避坑

## 标题公式

- `{语言/框架} {报错信息或关键词} 解决`
- `{功能} 实现：{环境} + 完整步骤`
- `{对比}：{A} vs {B} 在 {场景} 怎么选`

## 分发要点

- **分类**：选对二级分类，影响搜索与推荐
- **环境块**：OS、版本、依赖版本号必填
- **关键词**：标题与首段含主查询（报错、API 名）
- **原创**：代码与表述勿与其它平台 1:1 复制

## 发布 checklist（不写进 output）

- [ ] 标题 ≤70 字，像用户会搜的问句
- [ ] 环境/版本已写明
- [ ] 分步编号清晰
