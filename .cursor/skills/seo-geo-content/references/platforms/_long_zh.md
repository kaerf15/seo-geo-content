# 长文（中文）

**适用**：`zhihu` `wechat` `toutiao`  
**数值约束**：各平台 key → [platform_rules.json](../../rules/platform_rules.json)

## 产出结构

```markdown
# {标题}

{开头：钩子或直接给判断，自然段，勿写「**短答**：」}

## {小节}

…

{参考来源 / 行动清单 / CTA}
```

## 写作要点

- 主查询在标题或首段前 2 句；每个 `##` 对应一个可搜索问题
- 数据标来源；经验标「个人/团队实践」
- 忌：长铺垫后才给判断；断言无出处；硬广收尾；YAML / 元数据块 / 写作标签
