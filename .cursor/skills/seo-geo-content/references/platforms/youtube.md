# YouTube Script

> Full English video script, not a short-form cut.

产出格式 → [formats.md](../formats.md)（**中长视频** + storyboard）

## 约束

- **Duration**：120–900 seconds
- **语气**：clear, explanatory, trust-building
- **忌**：fake hype; mid-section repetition without new info
- **结构**：0–10s hook → 10–30s conclusion → expanded sections → storyboard

## Title formulas (for publish metadata)

- `How to {X} (without {common mistake})`
- `{Topic} explained in {N} minutes`
- `I tried {X} for {time} — here's what happened`

## 分发要点

- **Description**：first 2 lines = value prop + keywords; timestamps if chapters
- **Thumbnail**：3–5 words max; face or contrast object
- **Retention**：pattern break every 30–60s (b-roll, chart, cut)
- **SEO**：primary query in title + spoken in first 30s

## 发布 checklist（不写进 output）

- [ ] Hook + thesis in first 30 seconds of script
- [ ] Storyboard covers full runtime
- [ ] Description block drafted (can sit after storyboard in output)
