# Own Blog

> 建立认知、给判断、引回核心资产。可与 landing 分工：blog 深、landing 转化。

产出格式 → [formats.md](../formats.md)（**站内** + frontmatter）· GEO → [geo.md](../geo.md)

## 约束

- **篇幅**：1000–3000 字
- **标题**：≤60 字
- **首段直答**：40–80 字
- **语气**：professional, evidence-first
- **忌**：纯资料搬运；无出处断言；与 landing 全文重复
- **结构**：frontmatter → 首段直答 → `##` → 延伸阅读 → 发布元数据

## 标题公式

- `{判断}：{支撑理由的关键词}`
- `{年份} {主题} notes — {takeaway}`
- `What we learned about {X} (and what we'd do differently)`

## 分发要点

- **Frontmatter**：title, description, date, updated, tags（见 formats.md）
- **Internal links**：链到 landing、文档、相关 post；锚文本自然
- **Canonical**：跨平台改编时的**信息源**；其它平台摘片段，不整段复制
- **RSS/SEO**：description 含主查询；updated 随事实变更而改

## 发布 checklist（不写进 output）

- [ ] YAML frontmatter 完整
- [ ] 首段 40–80 字直答
- [ ] 延伸阅读 ≥1 条站内链（有 URL 才写）
- [ ] 发布元数据块含 og + schema 提示
