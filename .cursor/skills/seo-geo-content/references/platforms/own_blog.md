# Own Blog

**archetype**: [_geo.md](./_geo.md) · **rules**: `own_blog`

> 建立认知、给判断、引回核心资产。blog 深、landing 转化。

## 差异

- **语气**：professional, evidence-first
- **结构**：`# 标题` → 首段直答（自然段）→ `##` 小节
- **忌**：纯资料搬运；与 landing 全文重复；元数据块、写作标签

## 标题公式

- `{判断}：{支撑理由的关键词}`
- `{年份} {主题} notes — {takeaway}`

## 分发

- 文内自然链到 landing、文档；锚文本自然
- 跨平台改编时的 **信息源**；其它平台摘片段

## 自检

- [ ] 仅含可发布正文，无 YAML / 发布元数据 / **短答** 等标签
- [ ] 首段 40–80 字直答，主查询在标题或首段
- [ ] 每个 `##` 首句可单独摘引
