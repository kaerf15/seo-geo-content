# 公众号文章

**archetype**: [_long_zh.md](./_long_zh.md) · **rules**: `wechat` · **example**: [wechat-good.md](../../examples/wechat-good.md)

> 写给订阅者的内参，不是广场短内容。

## 差异

- **语气**：稳、清楚、有承接
- **结构**：开头钩子 → `##` 分节 → **行动清单** → CTA
- **忌**：平铺直叙；新闻稿腔；无行动清单

## 标题公式

- `{订阅者身份} + {本周/本月判断}`
- `{一个反常识观点}（附方法）`
- `{数字清单}：{具体收益}`

## 分发

- 摘要 ≤120 字，含核心判断
- CTA 指向社群/表单/回复关键词，与菜单栏一致

## 自检

- [ ] 含行动清单（≥3 条可执行项）
- [ ] CTA 与转化目标一致
