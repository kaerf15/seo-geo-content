# 公众号文章

> 写给订阅者的内参，不是广场短内容。

产出格式 → [formats.md](../formats.md)（**长文**）

## 约束

- **篇幅**：1000–3000 字
- **标题**：≤30 字
- **语气**：稳、清楚、有承接
- **忌**：平铺直叙；新闻稿腔；无行动清单
- **结构**：开头钩子 → `##` 分节 → **行动清单** → CTA

## 标题公式

- `{订阅者身份} + {本周/本月判断}`
- `{一个反常识观点}（附方法）`
- `{数字清单}：{具体收益}`

## 分发要点

- **摘要**：≤120 字，含核心判断，可独立于标题理解
- **排版**：关键句加粗；清单优于长段
- **私域承接**：CTA 指向社群/表单/回复关键词，与菜单栏一致
- **时机**：工作日上午或晚间阅读峰；系列文保持固定栏目名

## 发布 checklist（不写进 output）

- [ ] 标题 ≤30 字
- [ ] 含行动清单（≥3 条可执行项）
- [ ] CTA 与转化目标一致
