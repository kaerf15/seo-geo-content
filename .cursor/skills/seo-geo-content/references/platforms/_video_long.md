# 中长视频

**适用**：`bilibili` `youtube`  
**数值约束**：各平台 key → [platform_rules.json](../../rules/platform_rules.json)

## 产出结构

```markdown
# {标题}

{简介：前 2 行含关键词 + 价值承诺}

## 口播

{可照读全文，标注时间段}

## 分镜表

| 镜号 | 时长 | 画面 | 口播/字幕 | 字幕要点 | BGM/音效 | 备注 |
|------|------|------|-----------|----------|----------|------|
| 1 | 0–5s | … | … | … | … | 钩子 |
```

## 写作要点

- 开场给出「为什么要看下去」；核心结论前置
- 分镜表覆盖全片时长；每 30–60s 有信息增量或画面变化
- 标题下简介段含主查询与关键词（即发布用的 Description 文案，写在正文内，不单开元数据块）
- output 仅含标题、简介、口播、分镜表，不加发布元数据节
