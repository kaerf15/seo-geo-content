# Twitter / X 线程

> 高密度、观点锋利的英文线程。

产出格式 → [formats.md](../formats.md)（**线程**）

## 约束

- **条数**：5–12 条
- **单条**：≤280 字符
- **语气**：sharp, concise, insight-first
- **忌**：重复同一观点；首条不够强；每条依赖上一条才能懂
- **结构**：首条钩子 → 每条一观点 → 至少一例或数字 → 收尾 CTA

## 标题公式（首条）

- `Hot take: {contrarian claim}. Thread 🧵`
- `{N} lessons from {experience} (that {audience} ignores):`
- `Most {audience} get {X} wrong. Here's what actually works:`

## 分发要点

- **首条**：含完整钩子 + 价值承诺；可独立传播
- **每条**：一个 idea + 一句 evidence；避免「1/12 介绍背景」水条
- **链接**：收尾一条放 CTA；中间条少链，防降权
- **可扫读**：数字、箭头、短句；少从句套从句

## 发布 checklist（不写进 output）

- [ ] 5–12 条；每条 ≤280 字符
- [ ] 首条可独立理解
- [ ] 至少一条含例子或数字
