# 百家号文章

> 搜索分发长文：先答题，再展开，不要写成泛博客。

产出格式 → [formats.md](../formats.md)（**长文**）· GEO → [geo.md](../geo.md)

## 约束

- **篇幅**：800–2200 字
- **标题**：≤40 字
- **首段直答**：40–80 字
- **FAQ**：3–8 条，单条 30–120 字
- **语气**：answer-first, scan-friendly
- **忌**：站内博客腔；长铺垫后才给答案
- **结构**：首段直答 → `##` 小节 → `## 常见问题` → CTA

## 标题公式

- `{主查询}？{一句话答案关键词}`
- `{年份/场景}{品类}怎么选：{N} 个标准`
- `{是什么} — {定义 + 适合谁}`

## 分发要点

- **搜索意图**：标题 = 用户会搜的问句；首段 40–80 字可单独成摘引
- **FAQ 原子化**：每条 Q 完整、A 先结论；不依赖上文
- **时效**：正文注明发布/更新日期（事实依据允许时）
- **原创**：不与其它平台整段重复（参见 [adaptation.md](../adaptation.md)）

## 发布 checklist（不写进 output）

- [ ] 首段 40–80 字直答
- [ ] FAQ 3–8 条
- [ ] 主查询在标题或首段
