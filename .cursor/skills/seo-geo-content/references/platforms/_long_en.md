# Long-form (English)

**Applies to**: `medium` `substack` `hackernoon` `linkedin` `quora`  
**Numeric rules**: platform key → [platform_rules.json](../../rules/platform_rules.json)

## Output structure

```markdown
# {Title}

{Hook / TL;DR / short answer}

## {Section}

…

{CTA}
```

## Writing notes

- Primary query in title or first paragraph
- One idea per section; scannable paragraphs
- No marketing fluff; evidence or first-person experience
- No YAML process fields, publish-metadata blocks, or labels like **TL;DR:**
