# 视频号脚本

> 微信生态：可转发、私聊、进私域。

产出格式 → [formats.md](../formats.md)（**短视频** + 分镜表）

## 约束

- **时长**：30–60 秒
- **语气**：结果前置，轻私域承接
- **忌**：公域爆款腔；纯硬广；无承接动作
- **结构**：0–3s 钩子 → 3–30s 核心结论 → 45–60s CTA → 分镜表

## 标题公式（发布用，可不写入 output）

- `{人群} + {结果}` — 例：「小团队会后整理省 15 分钟」
- `{一个可转发的事实判断}`

## 分发要点

- **社交货币**：内容要「值得转发给同事」— 具体方法 > 情绪
- **私域承接**：CTA 指向企微/公众号/社群，与账号定位一致
- **封面**：少大字报；清晰人脸或场景更利转发
- **时长**：30–45s 完播率通常优于硬凑 60s

## 发布 checklist（不写进 output）

- [ ] 45–60s 有明确 CTA（关注/加微信/看链接）
- [ ] 分镜表含字幕要点
- [ ] 语气适合微信熟人圈，非抖音喊麦
