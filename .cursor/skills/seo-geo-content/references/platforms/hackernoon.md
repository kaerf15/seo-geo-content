# HackerNoon Article

**archetype**: [_long_en.md](./_long_en.md) · **rules**: `hackernoon`

> Technical media piece — sharper angle than a generic dev blog.

## 差异

- **语气**：sharp, technical-media, opinionated
- **结构**：thesis → evidence → angle → closing judgment
- **忌**：plain tutorial tone; no clear opinion

## 标题公式

- `{Technology} is not the problem. {X} is.`
- `Stop {common practice}. Do {alternative} instead.`
- `What {role} gets wrong about {topic}`

## 分发

- Claim in paragraph 1; code snippets or linked sources
- Avoid vendor pitch disguised as thought leadership

## 自检

- [ ] Thesis in opening
- [ ] Closing judgment, not generic summary
