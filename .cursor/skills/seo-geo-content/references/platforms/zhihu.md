# 知乎回答 / 文章

**archetype**: [_long_zh.md](./_long_zh.md) · **rules**: `zhihu` · **example**: [zhihu-good.md](../../examples/zhihu-good.md)

> 高质量专业回答，不像品牌软文。

## 差异

- **语气**：专业、克制、有依据
- **结构**：开头 100 字内完整回答（自然段）→ `##` 分节论证 → 参考来源
- **忌**：先铺垫后结论；断言无出处；结尾硬广

## 标题公式

- `{要不要/值不值} + {具体场景}？{明确结论}`
- `{人群}如何{解决 X}：{N 个可执行标准}`
- `{常见误区} — {反直觉判断}`

## 分发

- 盐选/专栏：小节标题用问题式
- 开头 100 字内给可单独摘引的判断（GEO，勿写「**短答**：」标签）

## 自检

- [ ] 开头直给判断，非「随着…的发展」
- [ ] 无 YAML、元数据块、写作标签
- [ ] 文末有参考或经验声明
