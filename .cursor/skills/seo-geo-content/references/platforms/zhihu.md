# 知乎回答 / 文章

> 高质量专业回答，不像品牌软文。

产出格式 → [formats.md](../formats.md)（**长文**）· 示例 → [zhihu-good.md](../../examples/zhihu-good.md)

## 约束

- **篇幅**：1200–3000 字
- **标题**：≤40 字
- **语气**：专业、克制、有依据
- **忌**：先铺垫后结论；断言无出处；结尾硬广
- **结构**：100 字内完整短答 → `##` 分节论证 → 参考来源

## 标题公式

- `{要不要/值不值} + {具体场景}？{明确结论}` 
- `{人群}如何{解决 X}：{N 个可执行标准}`
- `{常见误区} — {反直觉判断}`

## 分发要点

- **盐选/专栏**：若偏教程，小节标题用问题式，便于搜索与目录
- **引用**：数据标来源；经验标「个人/团队实践」
- **SEO**：标题含主查询；每个 `##` 对应一个搜索问题
- **GEO**：开头 100 字内给可单独摘引的短答

## 发布 checklist（不写进 output）

- [ ] 标题 ≤40 字；正文 1200–3000 字
- [ ] 开头有短答，非「随着…的发展」
- [ ] 文末有参考或经验声明
