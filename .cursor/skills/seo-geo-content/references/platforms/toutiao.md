# 今日头条文章

**archetype**: [_long_zh.md](./_long_zh.md) · **rules**: `toutiao`

> 信息流长文：先判断，再用案例把人读下去。

## 差异

- **语气**：readable, fast, information-feed-native
- **结构**：先结论 → 时效背景 → 案例/观察 → 明确建议
- **忌**：空观点；小标题重复；长铺垫

## 标题公式

- `{热点/时效词} + {判断}`
- `{数字} + {现象} + {怎么办}`
- `{地区/行业可选} + {具体问题}`

## 分发

- 前三段必须出现核心判断
- 案例无事实依据时改为「常见情况是」

## 自检

- [ ] 首段 3 行内有明确判断
- [ ] 至少 1 个案例或观察支撑
