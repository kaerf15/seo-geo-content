# 今日头条文章

> 信息流长文：先判断，再用案例把人读下去。

产出格式 → [formats.md](../formats.md)（**长文**）

## 约束

- **篇幅**：800–2000 字
- **标题**：≤35 字
- **语气**：readable, fast, information-feed-native
- **忌**：空观点；小标题重复；长铺垫
- **结构**：先结论 → 时效背景 → 案例/观察 → 明确建议

## 标题公式

- `{热点/时效词} + {判断}` — 例：「2025 小团队选型：会议工具别贪多」
- `{数字} + {现象} + {怎么办}`
- `{地区/行业可选} + {具体问题}`

## 分发要点

- **前三段**：必须出现核心判断，否则信息流划走
- **小标题**：不重复同一关键词；每节一个新信息点
- **案例**：用「某团队/某行业」需有事实依据，否则改为「常见情况是」
- **SEO**：标题含主查询；首段含定义或判断

## 发布 checklist（不写进 output）

- [ ] 标题 ≤35 字
- [ ] 首段 3 行内有明确判断
- [ ] 至少 1 个案例或观察支撑
