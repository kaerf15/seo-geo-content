# B站视频脚本

> 中文中长视频：讲清楚，不是纯切片。

产出格式 → [formats.md](../formats.md)（**中长视频** + 分镜表）

## 约束

- **时长**：60–300 秒
- **语气**：knowledge-first, steady, explanatory
- **忌**：纯切片感；只有结论没有展开
- **结构**：0–5s 钩子 → 核心结论 → 展开解释段 → 分镜表

## 标题公式（发布用）

- `{主题}：{结论或反差}` — 例：「AI 会议纪要：小团队选型 3 标准」
- `{教程向} 从 0 到 1 {完成 X}`

## 分发要点

- **简介**：前 2 行含关键词 + 时间戳预告（若有章节）
- **封面**：16:10 或 16:9；标题 ≤14 字可读
- **弹幕点**：设计 1–2 处可吐槽/共鸣句，提高互动
- **系列**：同系列标题格式统一，利于追更

## 发布 checklist（不写进 output）

- [ ] 简介 ≤250 字，含核心关键词
- [ ] 分镜表覆盖全片时长
- [ ] 60s 内给出「为什么要看下去」
