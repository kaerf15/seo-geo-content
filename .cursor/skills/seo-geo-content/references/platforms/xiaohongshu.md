# 小红书内容

> 平台原生种草，不是企业宣传稿。

产出格式 → [formats.md](../formats.md)（**短帖**）· 示例 → [xiaohongshu-good.md](../../examples/xiaohongshu-good.md)

## 约束

- **篇幅**：300–800 字
- **标题**：≤20 字
- **标签**：5–10 个
- **语气**：真实、口语、轻种草
- **忌**：机构口吻；硬广；「大家好」「重磅推出」
- **结构**：首句钩子、场景或第一人称、清单/分点、收尾 CTA

## 标题公式

- `{具体场景/痛点} + {结果或反差}` — 例：「开了 3 年会，终于不用抄待办了」
- `{数字} + {人群} + {解法}` — 例：「小团队 8 人，会议纪要只留 1 个工具」
- `{踩坑声明} + {筛选标准}` — 例：「换过 4 个 AI 纪要，我只看 3 点」

## 分发要点

- **封面**：大字 ≤8 字 + 高对比；人脸/对比图优于纯 Logo
- **首图决定点击**：标题与封面同一记忆点，不两套话术
- **标签**：2 个大词（品类）+ 3–5 个长尾（场景/人群）；不堆品牌名
- **互动**：结尾问具体场景问题，便于评论区补关键词

## 发布 checklist（不写进 output）

- [ ] 标题 ≤20 字；正文 300–800 字
- [ ] 标签 5–10 个
- [ ] 首句非寒暄，直接进入场景或结果
