# 抖音脚本

> 公域短视频：快抓人、快讲清结论。

产出格式 → [formats.md](../formats.md)（**短视频** + 分镜表）

## 约束

- **时长**：15–60 秒
- **语气**：fast, direct, public-feed-native
- **忌**：长铺垫；像微信私域视频；前 2 秒无信息
- **结构**：0–2s 钩子 → 2–10s 结论 → 解释/例子 → 分镜表

## 钩子类型（选 1）

- **反常识**：「会议纪要工具不是越多越好」
- **数字冲击**：「8 人团队，3 个工具减到 1 个」
- **痛点问句**：「你们会后整理要多久？」

## 分发要点

- **前三秒**：口播 + 字幕同时上结论关键词
- **字幕**：≤15 字/屏；关键词高亮
- **BGM**：弱于人声；知识类可不用强节奏
- **CTA**：关注/评论区关键词；60 秒内只一个动作

## 发布 checklist（不写进 output）

- [ ] 分镜表完整（镜号/时长/画面/口播/字幕/BGM）
- [ ] 2–10s 内出现核心结论
- [ ] 口播字数与 15–60 秒匹配（中文约 4–5 字/秒）
