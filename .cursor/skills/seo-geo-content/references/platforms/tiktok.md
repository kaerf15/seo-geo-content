# TikTok Script

> Native TikTok script, not a generic short clip.

产出格式 → [formats.md](../formats.md)（**短视频** + storyboard）

## 约束

- **Duration**：15–60 seconds
- **语气**：fast, native, scroll-stopping
- **忌**：ad-like delivery; slow open
- **结构**：0–2s hook → 2–8s conclusion → visual beats → storyboard

## Hook types (pick one)

- **Pattern interrupt**：「Stop doing {X} for {audience}.」
- **Specific number**：「We cut {metric} from {A} to {B}.」
- **Direct question**：「Still {pain} every week?」

## 分发要点

- **On-screen text**：mirror hook in first frame
- **Pacing**：jump cuts every 2–4s; no static talking head >5s
- **Sound**：trending audio optional; clarity > trend for B2B
- **CTA**：one action — follow, comment keyword, or link in bio

## 发布 checklist（不写进 output）

- [ ] Storyboard table complete
- [ ] Conclusion before 8s mark
- [ ] No placeholder shots in 画面 column
