# SEO / GEO 写作

**目标**：信念 → 行动（钩子 → 判断 → CTA）。SEO/GEO 放大传播，不替代营销。

## 写前

用户未说明时，只问缺项（勿写进 output）：

| 项 | 说明 |
|----|------|
| 主题 | 写什么 |
| 平台 | [platforms/INDEX.md](references/platforms/INDEX.md) |
| 受众 | 谁在看 |
| 转化目标 | 关注 / 私信 / 留资 / 购买等 |
| CTA | 具体动作；**勿编造链接** |
| 禁区 | 不能说的承诺、竞品、敏感表述 |
| 事实依据 | 无则正文不写具体数字与具名案例 |
| 主查询 | 无则从主题推断，见 [geo.md](references/geo.md) |

标题×3、开头×2 内心择优，正文只留一版。语气可参考 [examples/](examples/)。

## 产出

只写 **`output/<name>.md`**（默认 `{主题}-{platform}.md`）。全文可直发。

**禁止**：候选标题、过程 checklist、空占位、TBD。

多平台：每个平台一个文件，见 [adaptation.md](references/adaptation.md)。

## 执行

1. 打开 [platforms/INDEX.md](references/platforms/INDEX.md) 里该平台 `.md`（**约束以平台文件为准**）
2. 开发者文另读 [_dev_article.md](references/platforms/_dev_article.md)
3. [formats.md](references/formats.md) 排版 · [geo.md](references/geo.md) 主查询与摘引块
4. 落盘 → 回复路径或正文（不贴过程稿）

## 落盘前自检

- 篇幅、标题、标签符合平台 `.md`
- 主查询在标题或首段；百家号 / Landing / 博客首段 40–80 字直答
- 无编造；实体名一致；有 CTA；不像别的平台剪过来的

## 红线

不编造事实 · 一平台一文件 · 多篇则多个 `output/*.md` · 禁止跨平台换壳
